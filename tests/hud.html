GPU-resident HUD: font and chart validation

The native checks use an original geometric fixture font to validate pixel coverage numerically. Its triangles are not the showcase typeface. The real-font preview uses the app's Noto Sans source, or a local font you select. Files stay in this page.

The preview uses synthetic 120-frame timing data so spikes and the refresh-budget line can be inspected. It is not a benchmark. The normal showcase always uses live timing data.
