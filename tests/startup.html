Startup and continuous browser-refresh cadence

Two starts with the same full 65,536-row scene and real fonts: first after an optional cache clear, then a repeat start. The measured idle and scroll phases use the selected continuous rAF or yielding ASAP loop, with no per-frame await of GPU completion. No font, raster-quality or resolution reduction. This does not measure physical scanout or guarantee monitor-rate rendering.

Use the default 2 for paced vsync and 0 for an explicitly unbounded reference comparison. Per-frame acknowledgements are independent, not chained. ASAP has its own limit of eight submissions, independent of this vsync limit. Change order and repeat runs. Driver shader caches and HTTP caches are not cleared. An IndexedDB miss or worker restriction is reported, not assumed away. Selecting local fonts disables persistent scene caching.
