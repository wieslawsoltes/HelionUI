Native typography performance comparison

Compare exact GPU glyph caching with direct outline rasterization, or retained damage with full-frame rendering. Both arms use the same real fonts, 65,536 rows, layout, sorting and rendering resolution. This is not an old-release speedup or input-to-photon measurement. Explicit readbacks are confined to this test harness.

Fonts load once before measurement from pinned public Noto Sans URLs. Select your own static TrueType or WOFF1 files for an offline run; the files remain in this page. Font preparation, mount and cold-frame costs are recorded separately. Run multiple comparisons with alternating order before drawing conclusions.


No benchmark has run. A completed run is evidence only for the reported browser/device and configuration, not a universal performance guarantee.
