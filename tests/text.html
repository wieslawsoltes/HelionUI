Native typography and glyph-cache checks

This deterministic suite builds an original synthetic test font in memory (triangles and rectangles), then exercises the actual WebGPU pipelines. It needs no external font download. The main app’s Type page is the real-font visual specimen. Test-only readbacks verify layout, glyph placement, input state and exact cached/reference pixels. Passing this gate is not Unicode, visual-font or speed qualification.
