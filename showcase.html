Preparing retained buffers and compiling the compute pipelines.

WebGPU is required. The showcase uses synthetic data and real Noto Sans faces downloaded once at startup. Fonts and pipelines prepare in parallel. Local fonts can be selected instead. This browser-only startup panel disappears when the GPU surface is ready.

Tools & diagnostics




Font sources


The default downloads three pinned Noto Sans faces: Regular, Semibold and Italic. Font files are not embedded in this app. A versioned, lossless initial-scene cache speeds up repeat visits; it contains no live edits.


Choose local static TrueType-outline TTF, TTC or WOFF1 faces to work without font downloads. The browser reads these files locally; this app does not upload them. WOFF2, CFF and variable fonts are rejected explicitly. Applying fonts restarts the showcase and resets GPU edits.
